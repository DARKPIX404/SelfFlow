# SelfFlow

Android-приложение для саморазвития: распорядок дня, заметки, задачи, календарь, уведомления, будильник, виджеты, статистика и экспорт/импорт данных.

## Стек

- Kotlin + Jetpack Compose
- Material 3 / Material You
- Hilt (DI)
- Room (локальная БД)
- DataStore (настройки)
- AlarmManager + WorkManager (фоновые напоминания)
- Glance App Widgets
- Gson (экспорт/импорт и шаблоны)

## Минимальная версия Android

API 26 (Android 8.0)

## Что реализовано

- **Распорядок дня**: создание событий с датой/временем, повторением (нет/ежедневно/по будням/еженедельно), текстом уведомления; список с редактированием и свайпом для удаления.
- **Шаблоны рутин**: сохранение распорядка как шаблона и применение к диапазону дат с автоматическим созданием конкретных событий.
- **Задачи / тудушки**: статусы (к выполнению / в работе / выполнено), приоритет, срок, привязка к распорядку; фильтрация по статусу.
- **Заметки**: заголовок, текст, теги, поиск.
- **Календарь**: месячный вид с отметками дел на днях и деталями по выбранному дню.
- **Уведомления по распорядку**: напоминания через AlarmManager с настраиваемым текстом; повторяющиеся рутины разворачиваются в несколько ближайших срабатываний.
- **Будильник**: ежедневное напоминание ложиться спать и время пробуждения; оверлей поверх других приложений; запрос разрешений.
- **Виджет**: ближайшая рутина и количество оставшихся задач дня.
- **Статистика**: выполнение задач, распределение по статусам/приоритетам, рутины, заметки.
- **Экспорт/импорт**: резервное копирование данных в JSON через Storage Access Framework.
- **Темы**: светлая/тёмная тема и Material You (динамические цвета).

## Сборка

Проект открывается в Android Studio. Gradle wrapper отсутствует — студия предложит сгенерировать его при первом открытии (`gradle/wrapper/gradle-wrapper.jar` и `gradlew`).

### Готовый APK

Каждый пуш в `master` собирает debug APK через GitHub Actions. Скачать можно на странице **Actions → Build Debug APK → последний успешный запуск → артефакт `app-debug`**. APK подписан debug-ключом и устанавливается на телефон как обычное приложение.

### Релизная сборка

Для выпуска релиза нужно настроить подпись в `app/build.gradle.kts`:
1. Создать keystore: `keytool -genkey -v -keystore release.keystore -alias selfflow -keyalg RSA -keysize 2048 -validity 10000`.
2. Добавить `signingConfigs.release` и указать его в `buildTypes.release`.
3. Собрать: `./gradlew assembleRelease`.
