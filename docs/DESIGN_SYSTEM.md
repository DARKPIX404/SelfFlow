# SelfFlow 2.0 — Дизайн-система

**Концепция:** UX-уровня Telegram (скорость, тактильность, предсказуемость) в фирменной палитре Omarchy Samurai. Ноль стоковых Android-компонентов — всё своё.

## 2. Типографика

Шрифт: **Inter** (self-hosted variable wght 400–800). Заголовки — чуть плотнее трекинг (-0.02em).

| Стиль | Размер / вес | Где |
|---|---|---|
| `display` | 28 / 800 | Время на будильнике/фокусе, большие цифры |
| `title-lg` | 20 / 700 | Заголовки экранов |
| `title-md` | 17 / 600 | Карточки, секции |
| `body` | 15 / 450 | Основной текст, списки |
| `body-2` | 13 / 450 | Вторичный текст, подписи |
| `caption` | 12 / 500 | Капсы, бейджи, метки времени |
| `timer` | tabular-nums обязателен | Таймеры, счётчики |

## 3. Сетка и форма

- Базовый шаг 4dp. Отступы экрана 16, между карточками 12, внутри карточек 12–16.
- Радиусы: карточки/плашки 16, кнопки/чипы 12, bottom sheet top 24, аватары/кружки 50%.
- Тени мягкие, почти невидимые: `0 2px 12px rgba(0,0,0,.25)` (в тёмной теме тень ≠ elevation, elevation задаётся `--surface` vs `--bg`).
- Минимальная touch-зона 44×44dp.

## 4. Моушн и тактильность

- Длительности: micro (press/fade) 120ms, standard 200ms, sheet/route 280ms. Easing: `cubic-bezier(.2,.8,.2,1)` (ease-out как в Telegram), появление sheet — spring-ощущение через overshoot-кривую.
- Свайп-строки: фон действия раскрывается синхронно с жестом (0ms задержки), иконка действия — в середине жеста.
- Haptics (Capacitor): selection — при переключении вкладок/сегментов; light impact — tap по кнопкам; medium — завершение задачи/отметка привычки; notification — срабатывание будильника. Уважать настройку «отключить вибрацию».
- `prefers-reduced-motion` — отключать параллакс/спринги, оставлять fade.

## 5. Компоненты (UI-kit)

Всё реализуется с нуля в `src/lib/ui/`, без Material-виджетов.

**Навигация**
- `BottomTabBar` — 5 вкладок: Сегодня (home), Распорядок (calendar-clock), Задачи (check-square), Заметки (note), Ещё (dots → настройки/статистика/будильник/привычки/цели/фокус). Активная вкладка: акцентный цвет + мягкий «всплеск»; label появляется только у активной. Средняя вкладка (Задачи) — выделенная FAB-стилем? (опционально, реши на экране).
- `AppBar` — большой заголовок экрана слева, справа 1–2 иконки; скрывается при скролле вниз (Telegram-паттерн).

**Списки (сердце приложения)**
- `SwipeableRow` — как в Telegram: тянешь вправо — раскрывается действие (выполнено/отметить), влево — (отложить/удалить). Полное раскрытие жеста = выполнение действия с haptic-medium. Кнопки действий под контентом, цвет: success/warn.
- `ListItem` — leading-иконка или чек-круг, две строки текста (title + subtitle-время), trailing (бейдж/статус/многоточие-меню).
- `CheckCircle` — кастомный чек: незаполненный круг → заполненный success с анимацией заливки (150ms) + medium haptic.
- `Skeleton` — shimmer в цветах поверхности, при первой загрузке и pull-to-refresh.

**Панели и модалки**
- `BottomSheet` — наезд снизу, handle-полоска, свайп вниз закрывает, затемнение фона. Для форм создания/редактирования, фильтров, меню элемента.
- `Menu` — контекстное меню (⋯) как в Telegram: плавающая плашка с радиусом 12, пункты с иконками.
- `Dialog` — редко, только подтверждения деструктивных действий.

**Пикеры**
- `TimeWheel` — свой барабан времени (как в iOS/Telegram): бесконечная прокрутка, центральная выделенная строка, haptic-selection.
- `DateGrid` — свой месячный календарь: сетка, точки-события под числами (акцентный цвет), выбранный день — accent-soft круг.

**Контролы**
- `SegmentedControl` — фильтры (Все/Активные/Выполнено) со «скользящей» подложкой.
- `Chip` — теги, категории; выбранные — accent-soft + акцентный текст.
- `Toggle` — свой свитч (не Android): круглый бегунок, track с анимацией цвета.
- `Fab` — плавающая кнопка «+», accent, приподнятая над tab-bar на 16.
- `ProgressRing` / `ProgressBar` — кольцо (цели, фокус) и линия (привычки недели); анимация 300ms.
- `Heatmap` — ячейки 7×N (дни недели × недели), градации цвета: muted → parchment → success (тёплый переход, не зелёно-красный).

**Обратная связь**
- `Toast` — нижний плавающий, с action «Отменить» для удалений (soft-delete 4 сек).
- `EmptyState` — иллюстрация (тонкие линии в палитре) + подпись + CTA-кнопка.

**Иконки** — единый inline-SVG набор, stroke 1.8, скруглённые концы, 24dp. Стиль: Lucide-минимализм, но нарисованы своими патчами (не тянуть библиотеку ради 5 иконок).

## 6. Экраны — ключевые решения

- **Сегодня (дайджест)** — вертикальная лента утренней сводки: время подъёма → распорядок на день (таймлайн) → привычки (ряд CheckCircle) → задачи дня → активная цель. Pull-to-refresh перепланирует напоминания.
- **Распорядок** — таймлайн дня (как Telegram-чат с временными метками), свайп по строке: вправо «выполнено», влево «отложить/удалить». FAB → BottomSheet-форма: название, барабан времени, повторение (чипы), текст уведомления, дата старта.
- **Задачи** — секции по статусу, SegmentedControl-фильтр, свайп вправо — выполнить (с зелёной заливкой), влево — удалить. Карточка задачи: приоритет-полоска слева (warn-охра для HIGH).
- **Заметки** — список с поиском сверху (поиск по тексту+тегам), чипы тегов под превью, редактор — полноэкранный с авто-сохранением.
- **Привычки** — карточки в сетку: большой CheckCircle, название, streak «🔥 N дней» (своя иконка пламени в accent), внизу Heatmap месяца.
- **Цели** — карточки с ProgressRing, дедлайном, списком привязанных задач (чеклист внутри карточки).
- **Фокус** — полноэкранный тёмный экран: гигантский ProgressRing-таймер (display-типографика, tabular-nums), кнопки пауза/стоп, по завершении — полноэкранный оверлей-акцент + уведомление.
- **Будильник** — огромное время (display), две плашки wake/sleep с TimeWheel, тумблер включения, кнопка «проверить оверлей».
- **Настройки** — секции (Аккаунт и синк / Тема и звуки / Безопасность / Данные) на surface-плашках, всё кастомные строки-ListItem.

## 7. Принципы

1. **Скорость восприятия:** один экран — одна задача; вторичные действия прячутся в свайп/меню.
2. **Тактильность:** каждое значимое действие подтверждается haptic, каждый жест — визуальным откликом без задержек.
3. **Никаких дефолтных виджетов:** если компонента нет в UI-kit — он проектируется здесь, а не берётся из браузера/фреймворка.
4. **Палитра строго по токенам:** новые цвета только через дизайн-ревью (новые фичи используют существующие success/warn/accent).
