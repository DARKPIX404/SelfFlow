SelfFlow

Приложение для саморазвития: распорядок дня, задачи, заметки и календарь — всё в одном месте.

Скачать APK

·

Android 8.0 и выше · бесплатно · без рекламы

Возможности

Распорядок дня

События с повторениями, настраиваемыми уведомлениями и шаблонами рутин для целых диапазонов дат.

Задачи

Статусы, приоритеты, сроки и привязка к распорядку. Фильтрация по статусу.

Заметки

Заметки с заголовками, тегами и быстрым поиском.

Календарь

Месячный вид с отметками дел на днях и деталями выбранного дня.

Будильник и напоминания

Напоминания ложиться спать и просыпаться, оверлей поверх других приложений.

Виджет

Ближайшая рутина и оставшиеся задачи дня прямо на рабочем столе.

Статистика

Выполнение задач, распределение по статусам и приоритетам, активность по рутинам.

Экспорт и импорт

Резервное копирование всех данных в JSON через системный файловый доступ.

Как установить

  1. Скачайте APK по кнопке выше.
  2. Откройте загруженный файл. При необходимости разрешите установку из неизвестных источников для браузера — Android спросит об этом сам.
  3. Нажмите «Установить» — готово. Данные останутся на устройстве при обновлении поверх старой версии.
